# AMEX 고객 부도위험 예측

American Express의 익명화된 월별 고객 이력을 이용해 고객의 향후 부도위험을 예측하는 개인 프로젝트입니다. 대용량 데이터 처리, 고객 단위 검증, 신용평가용 파생변수 설계 및 표 데이터·시계열 모델 비교를 다룹니다.

## 로컬 검증 결과

### 초기 기준 모델과 Transformer

동일한 검증 고객 6,000명에서 측정했습니다. 두 모델의 학습 고객은 각각 18,000명입니다.

| 모델 | 입력 정보 | 검증 AMEX | 검증 ROC-AUC |
|---|---|---:|---:|
| LightGBM baseline | 고객별 최신 기록 188개 변수 | 0.75309 | 0.95516 |
| Transformer v1 | 고객별 최대 13개의 관측 기록 | **0.76342** | **0.95520** |

Transformer v1의 검증 AMEX는 최신 기록 LightGBM 대비 **0.01033** 높았습니다. LightGBM은 검증 AUC로, Transformer는 검증 AMEX로 최적 시점을 선택했습니다.

### 이력 모델의 5-fold 교차검증

기존 학습·검증 고객을 합친 개발 고객 24,000명에서 고객 단위 Stratified 5-fold 교차검증을 수행했습니다. 각 fold는 19,200명으로 학습하고 4,800명을 검증합니다. 초기 실험의 검증 고객 6,000명은 이 단계에서 개발 데이터에 포함되며, 별도의 최종 평가 고객 6,000명은 모델 선택에서 제외합니다.

아래 점수는 각 고객이 학습에 포함되지 않은 모델의 예측을 모은 **전체 OOF 예측에서 계산한 값**이며, fold 점수의 단순 평균이 아닙니다.

| 모델 | OOF AMEX | OOF 가중 정규화 Gini | OOF 가중 상위 4% 포착률 | OOF ROC-AUC |
|---|---:|---:|---:|---:|
| 최신 기록 LightGBM | 0.760696 | 0.909968 | 0.611424 | 0.954986 |
| 이력 LightGBM 31 leaves | 0.765700 | 0.914184 | 0.617216 | 0.957094 |
| 이력 LightGBM 63 leaves | 0.768474 | 0.914904 | 0.622043 | 0.957454 |
| 이력 CatBoost depth 6 | 0.771511 | 0.915669 | 0.627353 | 0.957837 |
| **CatBoost 75% + LightGBM 63 leaves 25%** | **0.771668** | **0.916786** | **0.626549** | **0.958395** |

선택된 앙상블의 OOF AMEX는 최신 기록 모델보다 **0.010972** 높았습니다. CatBoost 단독 대비 이득은 **0.000157**로 작습니다. 두 구성 모델의 OOF 예측 상관계수는 약 **0.98713**이었습니다.

OOF 성능 상위 두 모델의 확률 예측을 0/0.25/0.5/0.75/1 가중치로 비교해 조합을 선택했습니다. 선택 후 각 모델을 개발 고객 24,000명으로 재학습했습니다. 반복 횟수는 CV 최적 횟수의 중앙값으로 고정했습니다(CatBoost 700회, LightGBM 63 leaves 378회).

OOF는 최적 반복 횟수와 앙상블 선택에 사용됐으므로 독립적인 최종 평가가 아닙니다. 별도 6,000명 holdout의 성능표·신뢰구간은 아직 이 README에 제공되지 않았으므로 기재하지 않았습니다. **초기 6,000명 검증 점수, 24,000명 OOF 점수, Kaggle 테스트 점수는 서로 다른 평가 결과입니다.**

## 데이터

출처: [American Express - Default Prediction](https://www.kaggle.com/competitions/amex-default-prediction)

- 원본 학습 고객: 458,913명
- 프로젝트 표본: 고객 30,000명, 날짜별 이력 361,527행
- 고객별 관측 수: 1~13개, 평균 약 12.05개
- 표본 관측 날짜: 2017-03-01 ~ 2018-03-31
- 원본 이력 열: 190개 — 고객 ID, 날짜, 수치형 177개, 범주형 11개
- 고객별 정답: `target=1`은 대회 정의에 따른 부도, `target=0`은 비부도

| 접두사 | 공개된 변수 분류 |
|---|---|
| `D_` | 연체 관련 |
| `S_` | 소비·사용 관련 (`S_2`는 명세서 날짜) |
| `P_` | 납부·상환 관련 |
| `B_` | 잔액 관련 |
| `R_` | 위험 관련 |

변수는 익명화·정규화되어 있습니다. 접두사 외 개별 변수의 정확한 업무적 의미와 원래 단위는 알 수 없으므로 임의로 해석하지 않습니다.

정상 고객은 원 데이터에서 5%로 축소되어 제공되었습니다. 이 프로젝트 표본의 부도 비율 약 25.89%와 모델 출력값을 실제 운영 고객군의 부도율·부도확률로 직접 해석하지 않습니다.

데이터는 대회 이용 조건에 따르며, 원본·표본 데이터는 이 저장소에 포함하지 않습니다. Kaggle에서 직접 이용 조건을 확인하고 다운로드해야 합니다.

## 데이터 처리와 검증 설계

1. 정답 파일에서 `target` 비율을 유지해 고객 30,000명을 추출합니다 (`random_state=42`).
2. 원본 CSV를 50,000행씩 읽으면서 선택한 고객의 모든 이력을 수집합니다.
3. 고객 ID·날짜 중복과 고객 누락을 점검하고 Parquet으로 저장합니다.
4. 고객 단위로 학습 18,000명, 검증 6,000명, 최종 평가 6,000명을 분리합니다.
5. 분할 정보를 저장해 초기 모델 간 같은 고객으로 비교합니다.
6. Challenger 실험은 학습·검증 고객 24,000명을 합쳐 5-fold 모델 선택에 사용하고, 별도 최종 평가 고객 6,000명을 유지합니다.

전체 이력의 일부 행을 무작위로 뽑는 대신 고객 단위로 표본을 구성하여 이력이 잘리는 문제를 피했습니다. 표본 추출은 당시 Colab 실행에서 약 7.7분, 최종 DataFrame 메모리는 약 483.7MB였습니다. 이는 관측된 실행 결과이며 환경에 따라 달라집니다. 최대 메모리 사용량을 측정한 수치는 아닙니다.

최종 평가 데이터는 모델·가중치 선택에 사용하지 않는 것이 원칙입니다. 이미 결과를 확인한 최종 평가 데이터로 추가 튜닝했다면, 이후 보고에서 이를 독립적인 최종 평가로 표현하지 않아야 합니다.

## 모델

### LightGBM baseline

고객별 최신 날짜의 실제 기록 한 행을 선택하고 고객 ID·날짜를 제외한 설명변수를 사용합니다. 결측값과 범주형 변수를 처리하며, 검증 AUC 기준으로 학습을 중단합니다.

검증 위험점수 상위 10%인 600명 중 부도 고객은 572명이었습니다.

- 전체 검증 부도 고객 포착률: 36.81%
- 상위 10% 그룹 내 부도율: 95.33%

이는 정상 고객이 축소된 검증 표본 기준이며 대회 공식 AMEX 지표의 상위 4%와는 다른 보조 지표입니다.

### Transformer v1

고객의 날짜순 관측 기록을 시퀀스로 사용합니다.

- 수치형 값: 학습 고객 기록에서 구한 평균·표준편차로 변환, 변환값을 [-10, 10]으로 제한
- 수치형 결측 표시: 별도 입력
- 범주형: 학습 고객에서 만든 사전과 범주별 8차원 임베딩 사용
- 시간: 위치 임베딩과 마지막 명세서로부터의 일수 변환값 사용
- Padding: 최대 13개 기록으로 맞추고 실제 기록과 빈 자리를 마스크로 구분
- Encoder: 64차원, attention head 4개, 2개 층, dropout 0.2
- 출력: 마지막 실제 기록의 출력과 실제 기록 출력의 평균을 결합
- 학습: 이진 교차엔트로피, AdamW, 검증 AMEX 기준 최적 모델 저장

관측 기록 내 결측과 기록 자체가 없는 padding은 구분합니다. 검증·테스트에서 전처리 통계를 새로 학습하지 않습니다.

### 이력 CatBoost / LightGBM 앙상블

최신 기록에 고객별 이력 요약 변수를 추가합니다.

- 수치형: 평균·표준편차·최솟값·최댓값·유효 관측 수
- 변화량: 최신값−최초값, 최신값−직전 관측값, 최신값−전체 평균
- 최근 흐름: 최근 3회 평균−전체 평균
- 관측 상태: 결측 비율, 기록 수, 관측 기간
- 범주형: 최신 범주, 고유 범주 수, 관측된 범주 간 변경 횟수

최근 3회는 정확한 3개월을 뜻하지 않습니다. 범주 사전은 각 학습 데이터에서만 만들며, 고객별 이력 통계는 해당 고객의 관측 기록만 사용합니다.

LightGBM은 AMEX 기준 early stopping을 사용합니다. CatBoost는 AUC 기준 early stopping 후 50-tree 간격 후보와 마지막 지점을 AMEX로 비교하여 반복 횟수를 선택합니다.

최종 제출 예측은 다음과 같습니다.

`prediction = 0.75 × CatBoost + 0.25 × LightGBM`

테스트 CSV는 50,000행씩 처리하고 청크 경계에 걸린 고객의 기록을 다음 묶음으로 넘겨 이력을 보존합니다. 학습과 동일한 변수 생성 함수·열 순서·범주 사전을 사용하며, 공식 `sample_submission.csv`의 고객 ID 및 순서와 일치하는지 확인한 후 제출합니다.

## 평가 지표

대회 공식 지표는 다음 두 지표의 평균입니다.

`AMEX = (가중 정규화 Gini + 가중 상위 4% 부도 포착률) / 2`

정상 고객의 가중치는 20, 부도 고객의 가중치는 1입니다. 상위 4%는 원시 고객 수가 아니라 누적 가중치 기준입니다. 이 평가 가중치를 모델 학습 가중치로 자동 적용하지는 않습니다.

참고: [대회 평가 안내](https://www.kaggle.com/competitions/amex-default-prediction/overview/evaluation)

## 실행 방법

1. 노트북을 Google Colab에서 엽니다.
2. Google Drive를 연결합니다. 기본 프로젝트 경로는 `/content/drive/MyDrive/amex_project`입니다.
3. `01_load_dataset.ipynb`에서 Kaggle 인증 후 학습 데이터를 준비합니다. 토큰은 코드에 직접 기록하지 않습니다.
4. `02_baseline.ipynb`에서 고객 분할을 생성·저장하고 기준 모델을 학습합니다.
5. `04_transformer.ipynb`에서 저장된 분할을 불러와 시퀀스 전처리와 학습을 수행합니다. Transformer 학습에는 GPU 런타임을 권장합니다.
6. `03_ensemble.ipynb`에서 이력 변수 모델의 5-fold 비교, 앙상블 선택, 최종 재학습을 수행합니다. 모델 선택에는 최종 평가 데이터를 사용하지 않습니다.
7. 제출용 추론 셀에서 Kaggle 테스트 파일을 읽고 고객별 예측 CSV를 생성합니다. 점수는 로컬 검증과 Kaggle 제출 결과로 구분해 기록합니다.

주요 라이브러리는 `numpy`, `pandas`, `scikit-learn`, `lightgbm`, `torch`, `pyarrow`, `joblib`, `matplotlib`, `kaggle`이며, 이력 모델 앙상블에는 `catboost`를 사용합니다. 각 노트북의 설치 셀을 참고하세요. 정확한 실행 버전은 별도 환경 기록으로 관리해야 합니다.

노트북 저장과 Drive 산출물 저장은 별개입니다. 런타임이 초기화되면 `/content`의 임시 파일은 사라질 수 있습니다.

## 해석의 한계와 다음 실험

- 초기 Transformer는 단일 분할·seed 실험이고, Challenger는 고정 seed의 5-fold 실험입니다. 검증/OOF로 최적 시점과 모델을 선택했으므로 선택 과정의 낙관 편향이 있을 수 있습니다.
- 고객 간 분리는 했지만 미래 시점 성능을 검증하는 시간 외 검증은 아닙니다.
- 입력 정보가 다른 모델의 비교이므로 Transformer 자체의 우위로 해석하지 않습니다.
- 변수 중요도나 attention 가중치는 부도의 인과적 원인을 뜻하지 않습니다.
- 후속 실험으로 Transformer 최신 기록 직접 연결, 변화량 입력, 여러 seed 및 학습 고객 확대를 검토합니다.
- Kaggle 제출 점수는 확인됐지만 공식 대회 순위나 모델 차이의 통계적 유의성을 의미하지 않습니다. 리더보드를 반복 참조한 튜닝에도 과적합 가능성이 있습니다.
